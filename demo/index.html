Failure shaped the system.

01 // Prompt Loose guardrails

Fast output. Hidden assumptions. No proof.

02 // Constrain Executable contracts

03 // Select RL-inspired search

Parallel generators. Test model. Reward what survives.

Fluency is not reliability // evidence over confidence04 / 06
I started with loose prompting and got plausible but unreliable code. Guardrails turned requirements into executable contracts. The next direction is RL-inspired search: several generators, a test model that invents hard unit tests, and selection based on measured build and behavior results.
